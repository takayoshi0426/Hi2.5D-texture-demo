調査日：2026-10-16。制作対象：P20の歩行・短い爪攻撃ラフ。制作Skillは作らない。

## 検索と確認範囲

依頼された検索語「格闘ゲーム スプライトアニメーション」でPinterest検索ページを取得。英語の `fighting game sprite animation` / `fighting game sprite sheet` も試した。この環境では検索ページのHTMLから検索結果カードを取得できなかった。公開検索エンジンで `site:pinterest.com/pin/ 格闘ゲーム スプライト` を検索し、見つかった公開Pinを直接開いた。後続の外部検索にはチャレンジ画面になるものがあり、その結果は使用していない。

「Pinterest内の検索一覧をすべて閲覧した」「人気順を比較した」とは扱わない。ユーザー指定の1件と外部検索経由の5件、計6件の公開Pinを確認。3種類の実物資料を目視分析した。保存やボードへの投稿、ログインは行っていない。

## 1. キャミィ：全身の方向と攻撃のシルエット

- ユーザー指定：https://jp.pinterest.com/pin/450641506468757398/
- Pinに記載された出典：https://spritedatabase.net/file/205
- 出典ページの作品表記：Street Fighter Alpha 3、キャラクター：Cammy。
- 出典画像：https://spritedatabase.net/files/arcade/634/Sprite/Cammy.png （1494×4935）
- 静止シート全体と、待機・前進・後退・立ちパンチ周辺を拡大して確認。

前進10ポーズ・後退10ポーズを目視で数えた。腕を一定の形で前後させるだけでなく、肩幅、胸の見え方、骨盤と膝の向き、左右の重なりが変わる。拳を構えたままの移動であり、エリア内の普通の歩行と目的が違う。

立ちパンチは、構え・身体を引く姿勢・伸展・戻りを全身の別の形として描く。特に強い攻撃には伸びた線状の形や残像に相当する描き込みがあり、腕の関節位置を細かく均等に動かすことだけでは説明できない。脚の開きと体幹の方向も力の流れを支える。

**適用：** P20歩行では肩の前後差と腹面の向きを逆方向へ変える。爪攻撃は沈む・引く・速く伸ばす・反動・戻るという全身ポーズを別に作る。指先は歩行時の丸い手を伸ばすのではなく、開いた爪の輪郭を描く。

**未確認：** シートには保持時間、ゲーム中の再生順、繰り返し規則、入力・判定・ヒットストップがない。絵の横方向の間隔はゲーム中の移動量と解釈しない。抽出画像数を「実機の原画台帳数」と断定しない。

## 2. アレックスと思われる待機GIF：足元と体幹の変化を分ける

- 検索で見つかったPin：https://www.pinterest.com/pin/382735668320872044/
- 取得ページのcanonical表記：https://jp.pinterest.com/pin/9851692919114593/
- Pinのリンク先：GIFMAGAZINEの格闘ゲーム検索ページ。個別作品・制作元のページではない。
- 取得画像：https://i.pinimg.com/originals/ca/0e/92/ca0e929847250944a87504a9f2a432d5.jpg
- URLの拡張子はjpgだが、実ファイルは299×377のGIF、24フレーム、全コマ30ms、掲載ファイルの合計720ms。
- GIFを全24コマに展開して確認。ゲーム版・作者・公式素材かどうかは未確認。

広く開いた足元の形を概ね保ち、膝・腰・胸・肩・手の形が小さく変わる。待機でも完全な静止画ではないが、歩行のような大きな上下動や踏み替えを入れていない。肩・上腕・胸の面が一緒に変わるため、頭だけ上下させる呼吸とは見え方が違う。体格や顔の輪郭も追跡しやすい。

**適用：** 接地位置と上体の動きの大きさを別に設計する。P20爪攻撃は両足を地面に置いたまま上体と重心を動かす。待機ループそのものはP20では未制作。

**注意：** 30msはこの掲載GIFのエンコード値であり、実ゲームの保持時間ではない。足の全画素が固定されていると定量的に検証したわけではない。

## P20へ反映したことと限界

- 歩行：8つの主要位置、48枚の全身画像。16枚を3tick保持する比較も同じ0.8秒。支持脚と遊脚の交代、足裏の接地、上下動、肩と腰の方向差、マントとエラの遅れを設計。
- 爪攻撃：全身10枚の再生要素、異なる絵は9枚（最後に構えへ戻す）。保持は `8,4,3,1,3,2,4,5,6,12` tick、計48tick＝0.8秒。この配分は独自案で、キャミィから抽出した数字ではない。
- 制作方法は2D曲線・数値による全身の描画構成。各ポーズをPNGに書き出し、再生時は全身画像の切替だけ。3Dレンダーやラスタのパーツ分割は使わない。
- ただし、人が原画と中割りを一枚ずつ描いた完成アニメーションと同等ではない。足と体の関係を設計できても、関節の数値と同じ輪郭の関数から作るだけでは、表情・面・形の崩しを含む作画の自由度が不足する。これを格闘ゲーム品質の達成とは判定しない。
- 爪攻撃は素振り。相手・命中判定・ヒットストップ・カメラ演出は未実装。向きは1方向、反転表示のみ。既存の闘技場への組み込み、多方向・別仰角、完成彩色はまだ。
- 自動テストは接地計算・ループ・保持・操作の破綻を調べる。見栄えや演技の質を合格にするものではない。

研究用の元画像・抽出コマは一時領域で確認。公開ページには第三者の元シートを複製せず、リンクと所見、および独自ラフを掲載する。
