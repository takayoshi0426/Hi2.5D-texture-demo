# Hi2.5D Environment Studies

外部画像を使わない、Three.jsの土のテクスチャー比較サンプルです。

- 通常のリピート
- 大きな色むらを追加
- 3参照の簡易Hex tiling / stochastic blending

繰り返し回数・凹凸・色むらの調整、視点切替、ドラッグ回転に対応します。

## 開く

[ブラウザーでサンプルを開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/)

`index.html` をWebGL2対応ブラウザーで開けます。ビルド・サーバー・外部画像は不要です。

## 円形闘技場

[直径40mの円形闘技場を開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/arena.html)

床と外周を一体の形状にし、石材の目地・打撃痕・爪痕・焼け跡・補修区画を専用テクスチャーで表現するサンプルです。全景・真上・近景を切り替え、2m・5m・8mの比較模型で大きさを確認できます。

床全体と外周に固有の2Dレイヤーを重ね、模様をリピートせずに適用しています。石材ごとの開いた隙間や浮いた破片をなくし、風化むらを石の区切りをまたいで重ねています。`arena.html` も単体で動作し、外部通信は不要です。傷の一部は凹凸の陰影表現で、リアルタイムの破壊や戦闘アニメーションは含みません。

石の基底色には専用に生成した石灰岩画像を使用し、表面の鉱物粒・欠け・目地の砂利を描写しています。傷と補修跡は独立したレイヤーとして切り替えられます。画像もHTML内に含めているため、オフラインでも表示できます。

## P03 — 複数画像の40m石舞台

[ブラウザーでP03を開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/p03/)

床9枚（4096²）、縁と側面8枚（4096×1024）、階段1枚（2048²）。本体500三角形。床の描画密度は約305px/m。寄り・分割境界・縁と階段の視点、材質・光・形状の比較とGLB保存に対応します。高解像度のPC向け確認用試作で、全色画像のGPU展開はmipmap込みで概算960MiBです。

公開用ページはHTML・JavaScript・CSS・画像を分割して配信します。`p03/index.html`だけをローカルへ保存すると画像を読み込めないため、オンラインのURLから開いてください。Three.jsのライセンスは `p03/THREE-LICENSE.txt` を参照。制作スキルはまだ確定していません。
