# Hi2.5D Environment Studies

[P14・P21・添付HD2Dを選べる背景スタジオ](https://takayoshi0426.github.io/Hi2.5D-texture-demo/latest.html)（初期背景：P21 / 制作基準：P14）

r19では、P14の魔獣5種を各8方向・計40方向の透過画像にしました。相手への向きとカメラ位置に合わせて正面・斜め・側面・背面を表示し、手動移動中は進行方向にも追従します。向きの切り替え境界でのちらつきを抑え、サイズ・飛行・二体へのピント・GLB保存へ共通で反映しています。画像は選択された種類から読み込みます。

r18では、強すぎたぼけを自然で緩やかな表示へ調整しました。初期値はぼけ量12・鮮明な範囲の余白1.5m・ぼけへの移行距離8m。三項目を個別に調整して「このぼけを既定値に保存」でき、保存した値は同じブラウザーの起動時・初期状態で三背景共通に使います。「ぼけを標準に戻す」で自然な初期値へ戻せます。

r17では、二体の全身が収まる距離範囲を鮮明に保ち、その手前と奥を強くぼかす表示を三背景に追加しました。移動・飛行・カメラ変更に追従し、最大ぼけ半径の初期値は64です。共通設定の「二体の距離の外を強くぼかす」で切り替えられます。

r16では、飛行する魔獣が高度を変えて旋回・空中射撃・急降下攻撃を行います。飛べない魔獣はジャンプで回避・迎撃し、タイミングを合わせたパリィで魔法弾を撃ち返します。手動操作はSpaceで近接、Rで魔法弾、Jでジャンプ、Fでパリィ。三背景の戦闘・カメラ・自動ピントに共通で反映しています。

r15では、全5種のモンスターが相手へ向くよう左右反転を追加しました。位置の入れ替わりとカメラの回り込みに追従し、重なった際の反転のちらつきを抑えています。P14・P21・翠影の闘技場に共通で適用しています。

r14では、発光エフェクトが被写界深度の輪郭情報へ混ざり、画面が灰色・白くなる問題を修正しました。発光の大きさと色は維持し、前景カバレッジへの加算と不正なHDR値の発生を防いでいます。

r13では、コロッセオの読み込みを段階化しました。縮小済みの配信用画像を2件ずつ読み込み、応答停止や一時的な通信失敗を自動再試行します。背景を先に表示し、GPUメモリ不足時は一度だけ軽量表示へ復旧します。観客7,719席、門、AO、二体への自動ピントは維持しています。

r12では、二体の魔獣の全身へ常にピントを保つ自動F値調整を共通スタジオへ追加しました。待機・戦闘・飛行・自由カメラ・勝敗後にも対応し、奥行きが変わった瞬間に絞って両方を鮮明に保ちます。35度の画角とドリー移動を維持しています。

最新のr8は翠影の闘技場を細部の基準にし、三背景の素材の粒度と造形をそろえています。新しい石材16面から、P21の壁・縁石・門・長椅子・控え通路を再制作。門柱・アーチの石と四門の浮彫を立体化し、P14の笠石・倒木、三背景の折れた葉を持つシダを追加しました。壁と門の部材画像、追加造形はGLBにも保存されます。35度の固定画角と俯角10度までのカメラ、従来の戦闘・ピント設定は継続しています。

r7では、P21の四方の門を奥へ滑らかに暗くし、観客席の階をつなぐ面と影・AOを作り直しました。魔法陣と浮遊結晶は、発光する芯・にじみ・近くの石への光を重ねています。共通カメラは35度の固定画角とドリー移動、俯角10度まで。添付背景の石・木・植生もP14を基準に柔らかな光へ調整しています。

P14の背景制作を基準に、P21では新しい魔法文明のコロッセオを制作しました。P14の比較用ページも残しています。以下はこれまでの制作履歴です。各節の「スキル化は保留」は当時の状態で、現在は[P14までの制作Skill](https://github.com/takayoshi0426/Hi2.5D-modeling/tree/codex/hi25d-environment-skill-p14/.agents/skills/hi25d-environment-production)にまとめています。

初期の土の比較は、外部画像を使わないThree.jsサンプルです。

- 通常のリピート
- 大きな色むらを追加
- 3参照の簡易Hex tiling / stochastic blending

繰り返し回数・凹凸・色むらの調整、視点切替、ドラッグ回転に対応します。

## 円形闘技場

[直径40mの円形闘技場を開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/arena.html)

床と外周を一体の形状にし、石材の目地・打撃痕・爪痕・焼け跡・補修区画を専用テクスチャーで表現するサンプルです。全景・真上・近景を切り替え、2m・5m・8mの比較模型で大きさを確認できます。

石の基底色には専用に生成した石灰岩画像を使用し、表面の鉱物粒・欠け・目地の砂利を描写しています。傷と補修跡は独立したレイヤーとして切り替えられます。画像もHTML内に含めているため、オフラインでも表示できます。

## P14 — 円形絞りと薄レンズのぼけ

[P14を開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/p14/)

P13の舞台・森・遺跡・5種の2Dスプライトを保ち、被写界深度を改訂。薄レンズの錯乱円を計算し、前景・背景を別々に256点の円形絞りで積分してから合成します。小さな明点の明るさを保ち、合焦した色が背景のぼけへ漏れるのを抑え、前景の輪郭を自然に広げます。

絞りf値と撮影スケールを追加。実寸ではぼけの弱い40m舞台を、初期状態は1/10の模型・f/1.8として撮影します。「実寸のまま撮影」も選べます。合焦距離・クリック合焦、手前と奥の倍率、保護する合焦幅、最大ぼけ半径も調整可能です。

画面の色と深度を使う光学近似で、隠れた背景の完全な復元や光路追跡は含みません。画像・モデルの縮尺・GLB保存はP13を継承。中間の半解像度RGBA16F画像7枚を使うためGPU負荷は増えます。P01〜P13は比較用に保持し、制作スキル化は保留。Three.jsライセンスは `p14/THREE-LICENSE.txt`。

## 背景スタジオ — P14・P21・添付HD2Dの切替
