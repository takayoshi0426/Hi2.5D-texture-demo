# Hi2.5D Environment Studies

[最新の石舞台サンプルを開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/latest.html)（現在P13）

外部画像を使わない、Three.jsの土のテクスチャー比較サンプルです。

- 通常のリピート
- 大きな色むらを追加
- 3参照の簡易Hex tiling / stochastic blending

繰り返し回数・凹凸・色むらの調整、視点切替、ドラッグ回転に対応します。

## 開く

[ブラウザーでサンプルを開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/)

`index.html` をWebGL2対応ブラウザーで開けます。ビルド・サーバー・外部画像は不要です。

## GitHub Pages

Settings → Pages → Build and deployment で `Deploy from a branch`、`main`、`/ (root)` を指定すると、このフォルダを配信できます。

公開成果物のHTMLと説明・ライセンス情報のみを収録しています。

## 円形闘技場

[直径40mの円形闘技場を開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/arena.html)

床と外周を一体の形状にし、石材の目地・打撃痕・爪痕・焼け跡・補修区画を専用テクスチャーで表現するサンプルです。全景・真上・近景を切り替え、2m・5m・8mの比較模型で大きさを確認できます。

床全体と外周に固有の2Dレイヤーを重ね、模様をリピートせずに適用しています。石材ごとの開いた隙間や浮いた破片をなくし、風化むらを石の区切りをまたいで重ねています。`arena.html` も単体で動作し、外部通信は不要です。傷の一部は凹凸の陰影表現で、リアルタイムの破壊や戦闘アニメーションは含みません。

石の基底色には専用に生成した石灰岩画像を使用し、表面の鉱物粒・欠け・目地の砂利を描写しています。傷と補修跡は独立したレイヤーとして切り替えられます。画像もHTML内に含めているため、オフラインでも表示できます。

## P03 — 複数画像の40m石舞台

[ブラウザーでP03を開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/p03/)

床9枚（4096²）、縁と側面8枚（4096×1024）、階段1枚（2048²）。本体500三角形。床の描画密度は約305px/m。寄り・分割境界・縁と階段の視点、材質・光・形状の比較とGLB保存に対応します。高解像度のPC向け確認用試作で、全色画像のGPU展開はmipmap込みで概算960MiBです。

公開用ページはHTML・JavaScript・CSS・画像を分割して配信します。`p03/index.html`だけをローカルへ保存すると画像を読み込めないため、オンラインのURLから開いてください。Three.jsのライセンスは `p03/THREE-LICENSE.txt` を参照。制作スキルはまだ確定していません。

## P04 — 軽量化と経年変化

[ブラウザーでP04を開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/p04/)

P03の18画像を6画像へ削減。床4枚と外周1枚を2048²、階段1枚を1024²にしました。色画像のGPU展開量はmipmap込みの概算で960→112MiB、本体486三角形。床の密度は約102px/mです。

湿気・苔・土汚れ、赤茶色の染み、入口の踏み減り、局所の割れと欠けを色画像へ焼き込んでいます。「破損」「湿気・苔」「染み」「縁・階段」の視点から確認できます。破損は彩色による表現で、床に実際の穴は開けていません。

P03は比較用に残しています。制作コードと実験記録はHi2.5D-modelingのp04を参照。Three.jsのライセンスは `p04/THREE-LICENSE.txt` に含みます。

## P05 — 劣化32区画と造形

[ブラウザーでP05を開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/p05/)

P04の6画像（床4枚＋外周1枚を2K、階段1枚を1K）を保ち、劣化を32区画へ分散。床4か所を浅く沈め、標準64個の縁石に高さ・面取り・欠けを付け、側面に段と裾を加えました。5段の階段は下段へ広げ、角と踏面中央に摩耗の形を加えています。

標準2,024三角形、32辺の比較用は1,120三角形。色画像のGPU展開量は概算112MiB（全mipmap込み）です。「縁石」「破損・沈下」「東の沈下」「階段」から接写し、「無地」で造形だけを確認できます。GLB保存にも形状と6画像を含みます。

底面などを省いた表示用モデルで、衝突用の閉じたソリッドではありません。P04/P03を比較用に保持しています。Three.jsのライセンスは `p05/THREE-LICENSE.txt` に含みます。

## P08 — マルチUVの広域劣化とデカール

[P08を開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/p08/)

P07の浅い起伏と6枚の石肌画像を継承し、広い範囲の湿り・染み・土色の堆積をUV1で重ねました。床5か所と外周8か所には、土・苔・雨だれを投影デカールで追加。両方の層を個別に切り替え、濃さを変更できます。両方を消すとP07の彩色へ戻ります。

追加は広域劣化と3種のデカールをまとめた1K透過画像1枚。色画像は計7枚、概算117.3MiB（mipmap込み）。標準は本体1,936＋デカール1,044＝2,980三角形。GLB保存では選択した劣化を6画像へ焼き込み、1,936三角形の本体として保存します。P01〜P07を比較用に保持し、制作スキル化は保留。Three.jsライセンスは `p08/THREE-LICENSE.txt`。

## P09 — 周辺の第一段階

## P10 — 森の野外闘技場

P09の舞台・道・近い周辺を継承し、森の中の野外闘技場として背景を追加。84本の木、若木と下草、倒木、緩やかな地形と遠景の霞で奥行きを作りました。入口の道は開け、森・下草・霞を個別に切り替えられます。「森の全景」「森の道」「木立」「林床」「俯瞰」から確認できます。

## P11 — 深い森の遠景と、門・小屋の陰影

[P11を開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/p11/)

P10の40m舞台・石肌・広域劣化を継承。遠景パノラマで木立の隙間を埋め、石のアーチ門、控え壁、見張り小屋、水槽を追加しました。門の内側や屋根下、柱脚のAOと日光の遮蔽をUV2の実際のマップで重ね、深度に基づく被写界深度を加えています。各効果は個別に切り替えられ、ピントとぼけの強さも調整できます。「森の全景」「石の門」「小屋の陰」「水槽」から比較してください。

標準9,789三角形、追加の遺構480三角形。色画像10枚＋1KのAOとライトマップ各1枚。保存GLBは8,745三角形で、陰影を色へ統合し、パノラマも含めます。ぼけと霞は表示側の効果です。固定配置の焼き込みなので、遺構を隠した設置前比較ではAOとライトマップも切ってください。遠景は書割り、既存の近景樹冠は透過カードです。P01〜P10を保持し、制作スキル化は保留。Three.jsライセンスは `p11/THREE-LICENSE.txt`。

## P13 — 参考画像からの2Dスプライトと被写界深度

[P13を開く](https://takayoshi0426.github.io/Hi2.5D-texture-demo/p13/)

P12の舞台・森・遺跡・汚れ・陰影を継承。添付の参考画像5枚を、頭と手足を強調し細い羽根・配線・鱗を整理した2Dスプライトへ描き直しました。2mのピンクの両生類／土色のヒキガエル、4mの機械鳥／羽毛の鳥人を切り替え、8mの青い竜と比べられます。現在は各1ポーズの静止原画です。

合焦距離、くっきり見える前後の幅、ぼけの強さ、手前と奥のぼけを直接調整できます。対象への合焦と固定距離の切り替え、クリック合焦、3種のプリセットを追加。魔獣は実寸で接地し、カメラへ向く平面に描いています。

5種をまとめた2K透過画像1枚を追加し、色は11枚＋陰影2枚。標準19,497三角形、保存GLB18,453三角形。保存は表示中の種類と向きを含みます。カメラ追従・ぼけ・霞は表示側の機能です。P01〜P12を保持し、制作スキル化は保留。Three.jsライセンスは `p13/THREE-LICENSE.txt`。
